챙김 GitHub 업로드 방법

1. 이 ZIP의 압축을 풉니다.
2. index.html이 있는 폴더 안의 파일과 폴더 전체를 GitHub 저장소 최상위에 업로드합니다.
   ZIP 자체나 바깥 폴더 하나만 업로드하지 마세요.
3. GitHub 저장소 Settings > Pages를 엽니다.
4. Source: Deploy from a branch / Branch: main / 폴더: / (root)를 선택하고 Save를 누릅니다.
5. 게시 완료 후 Visit site를 누르면 앱 화면이 열립니다.

기본 배포는 API 키 없이 실제 날씨를 조회합니다.
기상청 API와 휴대폰 푸시 알림까지 쓰려면 backend/README.md의 서버 설정이 필요합니다.
API 키가 담긴 .env.local이나 .dev.vars 파일은 GitHub에 업로드하지 마세요.
